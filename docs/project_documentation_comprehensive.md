# مستندات و معرفی پروژه مدیریت هوشمند مکاتب (مکتب‌یار) - Rastyar

این سند شامل جزئیات فنی، معماری سیستم، قابلیت‌ها، و پیشنهادات برای توسعه آینده پروژه مدیریت هوشمند مکاتب است. این متن برای کپی کردن در فایل Word و ارائه رسمی آماده شده است.

---

## ۱. معرفی سیستم (System Overview)

پروژه "مکتب‌یار" (Rastyar) یک پلتفرم جامع و یکپارچه برای مدیریت امور آموزشی و اداری مکاتب افغانستان است. این سیستم با هدف دیجیتالی‌سازی فرآیندهای سنتی، افزایش شفافیت، و تسهیل ارتباط میان مدیران، استادان، شاگردان و و والدین طراحی شده است.

### اهداف اصلی پروژه:
- **یکپارچگی اطلاعات:** تمام سوابق تحصیلی، نمرات، حاضری و اطلاعات پرسنل در یک دیتابیس متمرکز ذخیره می‌شوند.
- **دسترسی نقش-محور:** هر کاربر (مدیر، معلم، شاگرد) فقط به اطلاعات مربوط به خود دسترسی دارد.
- **شفافیت و سرعت:** والدین می‌توانند به صورت آنی از وضعیت تحصیلی فرزندان خود مطلع شوند.
- **گزارش‌دهی هوشمند:** تولید اطلاع‌نامه‌های استاندارد معارف افغانستان و نمودارهای پیشرفت تحصیلی.

---

## ۲. معماری فنی (Technical Architecture)

این سیستم بر پایه جدیدترین تکنولوژی‌های توسعه وب ساخته شده است تا سرعت، امنیت و مقیاس‌پذیری را تضمین کند.

| بخش | تکنولوژی استفاده شده |
| :--- | :--- |
| **Frontend (رابط کاربری)** | Next.js 14 (App Router), React, Tailwind CSS |
| **Backend (سمت سرور)** | Next.js API Routes (Serverless Functions) |
| **Database (پایگاه داده)** | PostgreSQL (با استفاده از Prisma ORM) |
| **Authentication (احراز هویت)** | NextAuth.js (Secure Session Management) |
| **Real-time (ارتباط زنده)** | Polling mechanism (With plans to upgrade to WebSockets) |
| **Hosting (زیرساخت)** | قابلیت اجرا روی Vercel یا سرورهای شخصی Node.js |

## ۳. ماژول‌ها و قابلیت‌های کلیدی (Key Modules)

سیستم به چندین بخش اصلی تقسیم شده است که هر کدام وظایف خاصی را انجام می‌دهند:

### ۳.۱. مدیریت کاربران و نقش‌ها (User Roles)
سیستم دارای ۶ سطح دسترسی مختلف است:
1.  **SuperAdmin (مدیر کل سیستم):** دسترسی کامل به تمام مکاتب (در صورت استفاده چند مدرسه‌ای)، مدیریت ادمین‌ها.
2.  **Admin (مدیر مکتب):** مدیریت کامل یک مکتب، ثبت‌نام استادان و شاگردان، تعریف صنف‌ها.
3.  **Teacher (استاد):** مدیریت صنف‌های خود، ثبت نمرات، ثبت حاضری، ارتباط با والدین.
4.  **Student (شاگرد):** مشاهده نمرات، برنامه درسی، حاضری.
5.  **Parent (والدین):** نظارت بر وضعیت فرزندان، ارتباط مستقیم با مدرسه.
6.  **Staff (کارمندان):** ثبت ورود و خروج، اسکن QR کدها (گیت لاگ).

### ۳.۲. مدیریت آموزشی (Academic Management)
- **مدیریت صنف‌ها و مضامین:** تعریف ساختار آموزشی (صنف اول، دوم...) و مضامین درسی.
- **سیستم نمره‌دهی (Grading):** ثبت نمرات چهار و نیم ماهه (Midterm) و سالانه (Final). محاسبه اتوماتیک میانگین و تعیین وضعیت قبولی/مشروطی طبق استانداردهای معارف.
- **حاضری (Attendance):** ثبت روزانه حاضری (حاضر، غیرحاضر، مریض، رخصت).
- **اطلاع‌نامه (Report Cards):** تولید PDF اطلاع‌نامه با فرمت رسمی و استاندارد افغانستان (شامل لوگو، امضا، و نمرات).

### ۳.۳. سیستم ارتباطی و چت (Real-time Communication)
- **پیام‌رسان داخلی:** امکان چت متنی بین کاربران (استاد-شاگرد، والد-مدیر).
- **وضعیت آنلاین:** نمایش آنلاین بودن کاربران و آخرین زمان فعالیت (Last Seen).
- **نشانگر تایپ:** نمایش "در حال نوشتن..." هنگام تایپ کردن کاربر مقابل.
- **اعلانات:** نمایش تعداد پیام‌های خوانده نشده (Unread Badge).
- **بلاک کردن:** امکان مسدود کردن کاربران مزاحم.

### ۳.۴. دستیار هوشمند (AI Assistant)
- یکپارچگی با هوش مصنوعی برای پاسخ به سوالات کاربران.
- سیستم مدیریت مصرف (Credit Limit) برای کنترل هزینه‌های هوش مصنوعی.

### ۳.۵. سیستم ورود و خروج (Gate System)
- تولید QR Code برای هر کاربر (کارت شناسایی دیجیتال).
- اسکن QR Code توسط نگهبانی برای ثبت ساعت دقیق ورود و خروج.

## ۴. پیشنهادات برای بهبود و توسعه آینده (Recommendations & Roadmap)

برای ارتقای سیستم و تبدیل آن به یک محصول تجاری کامل، پیشنهادات زیر ارائه می‌شود:

### ۴.۱. پیشنهادات فنی (Technical Improvements)
1.  **ارتقاء سیستم چت:** در حال حاضر سیستم چت از روش Polling استفاده می‌کند (درخواست‌های مکرر به سرور). پیشنهاد می‌شود از **WebSockets (مانند Socket.io یا Pusher)** استفاده شود تا فشار روی سرور کاهش یابد و پیام‌ها کاملاً آنی (Instant) ارسال شوند.
2.  **بهینه‌سازی دیتابیس:** با افزایش تعداد رکوردها، نیاز به ایندکس‌گذاری (Indexing) روی فیلد‌های پرجستجو (مانند `studentId`, `classId`) وجود دارد.
3.  **تست‌های خودکار:** افزودن Unit Tests و Integration Tests برای اطمینان از عملکرد صحیح سیستم قبل از هر آپدیت.

### ۴.۲. ماژول‌های جدید (New Modules)
1.  **سیستم مالی و شهریه (Finance & Fees):**
    *   ثبت و مدیریت فیس‌های ماهانه شاگردان.
    *   صدور فاکتور و رسید دیجیتال.
    *   گزارش بدهکاران و درآمد مکتب.
2.  **آزمون آنلاین (Online Exams):**
    *   برگزاری امتحانات چهارگزینه‌ای و تشریحی به صورت آنلاین.
    *   تصحیح خودکار و اعلام نمره آنی.
3.  **مدیریت کتابخانه (Library Management):**
    *   ثبت کتاب‌ها و مدیریت امانات به شاگردان.
4.  **ایمپورت اکسل پیشرفته (Excel Import System):**
    *   همانطور که درخواست شد، امکان وارد کردن گروهی اطلاعات از فایل اکسل با قابلیت تطبیق هوشمند ستون‌ها.

### ۴.۳. تجربه کاربری (User Experience)
1.  **نسخه موبایل (PWA):** تبدیل وب‌سایت به یک اپلیکیشن قابل نصب (Progressive Web App) برای دسترسی راحت‌تر در گوشی‌های موبایل.
2.  **داشبورد تحلیلی:** نمایش نمودارهای گرافیکی از وضعیت نمرات، رشد یا افت تحصیلی شاگردان برای مدیران.

## ۵. نتیجه‌گیری

پروژه مکتب‌یار با معماری مدرن و قابلیت‌های متنوعی که دارد، پتانسیل بالایی برای تبدیل شدن به سیستم مرجع در مدارس دارد. با پیاده‌سازی ماژول مالی و سیستم آزمون آنلاین، این نرم‌افزار می‌تواند تمام نیازهای یک موسسه آموزشی را به صورت کامل پوشش دهد.
